# AnythingGraph website

Static landing page for the project.

## Preview locally

Open `index.html` in a browser, or serve the folder:

```bash
cd website
python3 -m http.server 8080
```

Then visit http://127.0.0.1:8080

## Deploy

Upload the `website/` folder to any static host (GitHub Pages, Netlify, S3, etc.). No build step required.
